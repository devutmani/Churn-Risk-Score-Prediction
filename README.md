# Customer Churn Risk Prediction (Windows)

Command Prompt ya PowerShell mein is folder ke andar:

    pip install -r requirements.txt
    python train.py
    streamlit run app.py

Phir browser mein http://localhost:8501 kholein.

Files: features.py (cleaning), train.py (model), app.py (dashboard), data/ (train.csv, test.csv), artifacts/ (results).
